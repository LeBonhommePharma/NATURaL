Iniciar una sesión

Usa una silla estable con espacio para moverte. Elige un plan y pulsa Iniciar sesión. Usa Pausa, Continuar y Terminar cuando lo necesites. Adapta los movimientos a tu comodidad. Requiere iOS / iPadOS 18+ o watchOS 10+.

Salud, historial y guardado

Elige permisos de Salud en Acerca de y privacidad. Una métrica ausente puede indicar falta de permiso, muestras o sensor compatible. Las sesiones locales aparecen en Historial. Si el guardado falla, reinténtalo desde el resumen. Si se indica almacenamiento temporal, mantén la app abierta mientras resuelves el problema: los datos temporales no sobreviven al cierre.

Informar de un problema

Envía la versión de la app, modelo del dispositivo, versión del sistema y pasos para reproducir el problema. Las capturas e informes de fallos ayudan; elimina los datos personales y de salud. Para problemas del Watch, revisa permisos de Salud y reintenta. Un error de guardado indica que no debes asumir que la sesión llegó a Salud.
